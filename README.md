# ☕ Java Journey

Plataforma interactiva para aprender Java desde cero, diseñada para estudiantes de 1ero BT Tecnologías de la Información (UTU).

**[→ Abrir la app](https://programacion1utu.github.io/javaJourney)**

---

## ¿Qué es?

Java Journey es una app web que integra explicaciones paso a paso con un editor de código Java en vivo (OneCompiler). Cada lección incluye:

- Explicación teórica con ejemplos
- Editor de código interactivo
- Panel de verificación de salida
- Pista disponible si se necesita ayuda
- Quiz de repaso al finalizar cada tema
- Botón para compartir el trabajo con la docente

## ¿Cómo usar la app?

1. Seleccionar un tema en el panel izquierdo
2. Leer la explicación y el ejemplo
3. Escribir el código en el editor (OneCompiler)
4. Ejecutar con el botón **Run**
5. Pegar la salida en el panel inferior y hacer clic en **✔ Verificar**
6. Cuando se logra la salida correcta, hacer clic en **📤 Compartir completo** para enviar el trabajo a la docente

## ¿Cómo compartir el trabajo?

1. Hacer clic en **📤 Compartir completo**
2. Pegar el link de OneCompiler si guardaste el código (opcional)
3. Hacer clic en **Copiar mensaje**
4. Pegar el mensaje donde indique la docente
