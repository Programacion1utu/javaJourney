Ejercicio 2

Calculadora con switch

lección 60

Completar el case de multiplicación y el de división (con verificación de divisor cero).

Sin verificación automática (usa Scanner). Entrada de ejemplo: 10 4 /.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        double a = sc.nextDouble();
        double b = sc.nextDouble();
        String op = sc.next();
        double resultado = 0;
        switch (op) {
            case "+": resultado = a + b; break;
            case "-": resultado = a - b; break;
            case "*": resultado = a * b; break;
            case "/":
                if (b != 0) {
                    resultado = a / b;
                } else {
                    System.out.println("Error: división por cero");
                    return;
                }
                break;
            default:
                System.out.println("Operador no válido");
                return;
        }
        System.out.printf("%.1f %s %.1f = %.2f%n", a, op, b, resultado);
    }
}
Salida
10.0 / 4.0 = 2.50
